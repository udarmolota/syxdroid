SyxDroid's built-in on-screen controls. PLACEHOLDER: this is still Deephall's layout (tested on a
Samsung S25 Ultra), copied as a starting point. It needs a Songs of Syx layout: Esc, Space (pause),
1-3 (speed), WASD/arrows, F-key hotkeys and an on-screen keyboard toggle (PLAN.md).
controls.json is the launcher's layout format; icons/ holds the images it names.

- storm_*.png: the StormDroid "Classic" icon pack by udarmolota, CC0 (see LICENSE-storm-icons.txt).
- deephall_*.png: cut from Mountaincore's own UI atlas (MIT, see the game's LICENSE) and turned into
  white glyphs so the launcher can tint them.
